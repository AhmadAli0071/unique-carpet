# Image guide — Unique Carpet & Interior

Every picture on this site is currently DRAWN by JavaScript as an SVG (js/art.js).
That is a placeholder, not a photograph.

To use a real photo, save it into this folder with the exact file name below. It
appears immediately — no code change, no rebuild. Delete the file and the drawn
artwork comes back. Nothing ever shows a broken image.

Format: .jpg, sRGB, quality ~80. Under 400 KB each; under 250 KB for product cards.

Use photographs you own or have licensed for commercial use. Your own shop and job
photos work best — they show the work a customer will actually get. If you are
moving images from another site you run, export them from that site's media library
rather than saving them off the page, so you keep the full-size originals.
